No2SQL

An MCP server and NuGet package that looks at a live MongoDB database, works out how the collections relate, and generates the SQL schema, seed data and ER diagrams to move it to a relational database. You drive it by asking your AI coding assistant.

C# .NET 10 MCP MongoDB SQL NuGet GitHub Actions
GitHub NuGet

The problem

Moving from MongoDB to a relational database is slow, manual work. Someone has to open every collection to see what the documents look like, guess which fields point at other collections, hand-write a CREATE TABLE for each one, write INSERT scripts to move the data, and then draw the ER diagram so the rest of the team understands the result.

MongoDB doesn't enforce relationships, so the hardest part is the guessing. Get a foreign key wrong and the migration either fails or silently loses meaning.

The approach

No2SQL reads the data itself instead of relying on documentation or naming conventions alone:

  • Sample up to 300 documents per collection and record each field's type and whether it's always present.
  • Find candidates: fields whose names look like references (*_id, *Id).
  • Confirm with values: normalize the IDs and check how many of a candidate field's values actually exist as primary keys in another collection. That ratio becomes a confidence score for the relationship.
  • Generate: MySQL tables with foreign keys, INSERT seed scripts, and ER diagrams in Mermaid, PlantUML and GraphViz DOT, all from the same analysis.

All of it is exposed as 10 MCP tools, so a developer can type "Generate SQL schema for database mydb" in GitHub Copilot, VS Code or Claude Desktop and get working output back.

Architecture

A .NET 10 MCP host that talks over stdio, plus four focused libraries and a test harness. Every request passes through a guardrails layer before it reaches the database.

Key decisions

Confirm with data, not just names

A field called userId is only a guess. Checking its values against real primary keys turns the guess into evidence, and the confidence score shows how strong that evidence is.

Let people override

Inference is a heuristic, so it can be wrong. The advanced schema tool accepts explicit relationship overrides, so a developer can correct or add links without fighting the tool.

Stream the seed data

Seeders make two passes. The first fixes a deterministic column order, and the second emits INSERT chunks that can each run on their own, so memory stays bounded on large collections. Nested arrays and documents are stored as JSON.

Secure by default

An AI assistant is calling into a real database, so every input is validated: identifier format and length, an optional database allowlist, admin/config/local blocked by default, and detection of prompt-injection markers.

No .NET required

The NuGet package ships self-contained executables for Windows, Linux and macOS (6 platform builds), so anyone can run it without installing .NET or creating a project.

Gate every release

A GitHub Actions pipeline builds the release, scans for vulnerable packages, runs a gitleaks secret scan, checks that no debug symbols ship in the package, and verifies the MCP manifest before anything is published.
